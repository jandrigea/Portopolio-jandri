Perkenalan Singkat

Nama saya Jandri Hartat Gea, seorang mahasiswa aktif jurusan Teknik Informatika di Universitas Pamulang. Saya memiliki ketertarikan mendalam pada bidang pengembangan perangkat lunak, khususnya web development dan mobile programming. Saya percaya bahwa teknologi adalah alat untuk menciptakan solusi nyata bagi masalah di masyarakat.

Selama menempuh pendidikan, saya aktif mengerjakan berbagai proyek akademik maupun pribadi, mulai dari aplikasi sederhana berbasis web hingga sistem informasi yang lebih kompleks. Saya juga senang mempelajari teknologi baru dan berkolaborasi dalam tim.
